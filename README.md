# *Internship / LCB (CNRS UMR7283)  - Myxoccocus xanthus*


Repository for image analysis of Myxococcus xanthus spores and their properties. 
All protocols can be found in this repository at:
- *Myxospores_isolation_individual_FBs_protocol*
- *Myxospores_image_processing_protocol*


### Imaging
Material
- FBs colonies were observed under stereoscope olympus
- Spores and vegettives cells were observed under epifluorescence microscope TIE

Image processing
- Fiji version 2.16.0 / ImageJ 1.54p ; Java 1.8.0_452
- Labkit - Pixel Classification plugin fiji integrated
- Python 3.14.6 | packaged by conda-forge
